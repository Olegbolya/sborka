## 2. Что сделать руками сейчас

1. **Секрет для деплоя `DEPLOY_SSH_KEY`.** Это тот же приватный SSH-ключ, которым вы заходите на сервер (`ssh -i ~/.ssh/bst_server deploy@95.105.7.135`). Из BST его скопировать нельзя — GitHub секреты не показывает, поэтому берём файл с вашего компьютера:
   1. Откройте PowerShell и выполните: `Get-Content $HOME\.ssh\bst_server -Raw | Set-Clipboard` — ключ скопирован в буфер обмена (на экран ничего не выводится).
   2. Откройте https://github.com/Olegbolya/sborka/settings/secrets/actions → **New repository secret** → Name: `DEPLOY_SSH_KEY` → в поле Secret вставьте (Ctrl+V) → **Add secret**.
   3. Очистите буфер: `Set-Clipboard -Value " "`.
   - Если файла нет (ошибка «не найден путь»): `dir $HOME\.ssh` — нужен файл **без** `.pub` (например `id_ed25519`); подставьте его имя в команду из шага 1.
   - Если ключа нет совсем: `ssh-keygen -t ed25519 -f $HOME\.ssh\blokum_deploy` (дважды Enter), затем добавьте открытую часть на сервер: `type $HOME\.ssh\blokum_deploy.pub | ssh deploy@95.105.7.135 "cat >> ~/.ssh/authorized_keys"` и используйте `blokum_deploy` в шаге 1.
   - Ключ **никому не присылайте** — ни в чат, ни в код.
2. **Домены** (решения 4–5): купить `blokum.ru` (и при желании `blokum-media.ru`), A-записи на `95.105.7.135`.
3. После задачи P0.4 — запустить подготовку сервера (инструкция появится в §4).
