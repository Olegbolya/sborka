# Сверка норм (P8.0)

Сверка норм из `05-LEGAL.md` §2 с действующими редакциями. Дата сверки — **10.11.2026**. Источники — правовые порталы и деловые издания (ссылки в таблицах); официальные тексты на publication.pravo.gov.ru и в Консультанте из рабочей среды агента недоступны, поэтому перед запуском юрист сверяет формулировки по официальному тексту.

Это не юридическая консультация: документ показывает, что проверено, что изменилось и что из этого следует для продукта.

Отметки: ✅ подтверждено по источнику · 🔄 изменилось, нужно действие · ⏳ не сверено в этой сессии (нет доступного источника — проверить при следующем проходе).

## 5. Что из этого следует

1. **Автоплатёж включать только вместе с кнопкой «Отвязать карту» и отменой подписки в один шаг** — это требование 376-ФЗ и условие ЮKassa. Пока автосписаний нет (оплата продления вручную), нарушения нет. Задачи P7.4 и P7.6.
2. **Вход только через VK ID, Яндекс ID и телефон** — теперь за нарушение штраф по ст. 13.55 КоАП; текущая реализация соответствует.
3. **Юристу** — сверить по официальным текстам строки с отметкой ⏳ и точную дату начала действия ст. 13.55 КоАП.
