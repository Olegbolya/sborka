# Промпт: рабочая сессия (Sonnet medium / Opus high)

Скопируйте всё, что ниже линии, и отправьте агенту. Для задач с пометкой «Opus» в `docs/PROGRESS.md` переключите модель на Opus (effort high), для остальных — Sonnet (effort medium).

---

Ты работаешь над проектом «Сборка» — репозиторий `Olegbolya/sborka`. Если репозитория нет в рабочей папке — подключи его с правом push и склонируй.

1. Прочитай `CLAUDE.md` и `docs/PROGRESS.md`. Это обязательные правила и текущее состояние.
2. Выполняй задачи плана по порядку, начиная со следующей незавершённой, строго по циклу задачи и DoD (`CLAUDE.md`, `docs/03-PLAN.md`). План мне на одобрение не присылай — делай.
3. Перед тем как отметить задачу ✅, перечитай её «Приёмку» и каждое требование из «Покрывает». Для каждого пункта ответь себе: где это в коде, каким тестом (с ID в названии) это проверено, запускал ли я этот тест. Если хоть на один вопрос ответа нет — задача не готова, продолжай её.
4. Для интерфейса сам сделай скриншоты (390, 1440, для редактора ещё 1024), открой их и опиши, что видишь. Исправь всё, что выглядит сломанным, обрезанным, наезжающим или «шаблонным».
5. Не останавливайся после одной задачи. Продолжай, пока: фаза не закончится (тогда напиши, что нужно ревью по `docs/prompts/REVIEW.md`), или все оставшиеся задачи не будут ждать меня, или контекст не начнёт заканчиваться (тогда сначала запиши в `docs/PROGRESS.md` точное место остановки).
6. Мне задавай только вопросы из `docs/00-OWNER-DECISIONS.md`. Технические решения принимай сам и записывай в `docs/DECISIONS.md`.
7. В конце — отчёт строго по шаблону из `CLAUDE.md` (раздел «Не сделано / частично» обязателен).
