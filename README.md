# Блокум

**blokum.ru** — конструктор интерактивных сборок: открытки, тесты, квизы, приглашения, опросы, квесты и **свои** мини-игры из универсальных блоков. Любой блок редактируется в любом свойстве, механику пользователь собирает сам из сценариев «Когда → Если → Сделать», тему — тоже сам, мемы и медиа загружает своими файлами. Создатель делится ссылкой или QR, участники проходят **без регистрации**, результаты приходят в личный кабинет.

Репозиторий называется `sborka` по рабочему названию — переименовывать не обязательно. Проект строится ИИ-агентом по плану в `docs/`. Кода пока нет — его пишет агент, начиная с задачи P0.1.

## Как вести работу (для владельца)

1. **Обычная задача** → модель **Sonnet**, effort **medium**. Задача с пометкой «Opus» в `docs/PROGRESS.md` → модель **Opus**, effort **high**.
2. Отправьте агенту текст из `docs/prompts/START.md`. Он сам возьмёт следующую задачу и пойдёт по плану.
3. Если агент остановился раньше, чем закончилась фаза, или отчитался «основное сделано» — отправьте `docs/prompts/CONTINUE.md`.
4. Когда агент сообщил, что фаза закончена, — **новый чат**, Opus high, `docs/prompts/REVIEW.md` с номером фазы. Найденное ревьюером снова отдаётся в работу через `START.md`.
5. Если чат стал очень длинным и агент начал путаться — откройте новый чат и отправьте `START.md`: всё состояние хранится в репозитории, а не в чате.
6. Вопросы, которые решаете только вы (деньги, статус, домены, доступы), собраны в `docs/00-OWNER-DECISIONS.md`.

## Что не даёт агенту «халтурить»

| Механизм | Что ловит |
|---|---|
| `CLAUDE.md` | Жёсткие правила: без заглушек, без сокращения объёма, без ослабления проверок, без раннего «готово», обязательный раздел «Не сделано» |
| `docs/03-PLAN.md` | У каждой задачи — ID требований и проверяемая приёмка; общий DoD для всех задач |
| `scripts/check-progress.mjs` | Нельзя отметить задачу ✅ без коммита, доказательства и теста **на каждое** требование (ID в названии теста); любое требование спецификации должно быть в плане |
| `scripts/check-forbidden.mjs` | TODO, «not implemented», пропущенные тесты, `@ts-ignore`, «упрощённая версия», «рыба» |
| `scripts/check-foreign-services.mjs` · `check-licenses.mjs` · `check-legal.mjs` | Иностранные сервисы, ассеты без лицензии, незаполненные юридические реквизиты |
| `.claude/hooks/stop-gate.mjs` | Не даёт агенту закончить ответ, пока есть заглушки, красные проверки, незакоммиченная или незапушенная работа, нет отчёта по шаблону |
| CI (`.github/workflows/ci.yml`) | Всё то же на каждый push; деплой только после зелёного CI |
| Ревью фазы моделью Opus | Независимая проверка, что требования реализованы по существу, а не формально |
